# Database Visualizers

This repository contains two database visualization projects and hosts the downloadable binaries for Tablescape:

- [`database-visualizer`](./database-visualizer) — an Astro-based database visualization experience.
- [`Tablescape`](./Tablescape) — the Tablescape desktop database workspace built with React, Vite, and Tauri.

It will also host the downloadable binaries for Helix Visualizer. The Helix Visualizer source currently lives in the [`helix-test` repository](https://github.com/RatikGambhir/helix-test) on GitHub.

Each project has its own setup and development instructions in its directory.
